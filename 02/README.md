# Задачи

## Container
https://leetcode.com/problems/container-with-most-water

Дан массив неотрицательных чисел `height`, где каждое число обозначает высоту вертикальной линии в точке с соответствующим индексом. Нужно найти две линии, которые вместе с осью абсцисс образуют контейнер, вмещающий наибольшее количество воды, и вернуть эту максимальную площадь.

Пример 1
Ввод: `height = [1,8,6,2,5,4,8,3,7]`
Вывод: 49

Пример 2
Ввод: `height = [1,1]`
Вывод: 1

## Difference
https://leetcode.com/problems/find-the-difference-of-two-arrays

Даны два массива целых чисел `nums1` и `nums2`. Нужно вернуть массив из двух списков:
- элементы, которые есть в `nums1`, но отсутствуют в `nums2`;
- элементы, которые есть в `nums2`, но отсутствуют в `nums1`.

Каждый элемент в результирующих списках должен быть уникальным.

Пример 1
Ввод: `nums1 = [1,2,3], nums2 = [2,4,6]`
Вывод: `[[1,3],[4,6]]`

## Duplicates
https://leetcode.com/problems/remove-duplicates-from-sorted-array

Дан отсортированный по неубыванию массив `nums`. Нужно удалить повторяющиеся элементы на месте так, чтобы каждый уникальный элемент встречался только один раз, сохранив относительный порядок. Вернуть новую длину массива.

Пример 1
Ввод: `nums = [1,1,2]`
Вывод: `2, nums = [1,2,_]`

Пример 2
Ввод: `nums = [0,0,1,1,1,2,2,3,3,4]`
Вывод: `5, nums = [0,1,2,3,4,_,_,_,_,_]`

## Hist
https://coderun.yandex.ru/problem/histogram

Читает символы со стандартного ввода (до EOF), подсчитывает частоту встречаемости каждого непробельного символа и строит гистограмму из символов `#`, где высота столбца соответствует количеству вхождений символа. Под гистограммой выводится строка из всех встретившихся уникальных символов.

Формат ввода
Произвольный текст, читаемый до конца ввода (EOF).

Формат вывода
Гистограмма из символов `#`, а под ней - строка уникальных символов, встретившихся во входных данных.

Пример 1
Ввод:
```
Hello, world!
```
Вывод:
```
     #   
     ##  
#########
!,Hdelorw
```

Пример 2
Ввод:
```
Twas brillig, and the slithy toves
Did gyre and gimble in the wabe;
All mimsy were the borogoves,
And the mome raths outgrabe.
```
Вывод:
```
         #              
         #              
         #              
         #              
         #              
         #         #    
         #  #      #    
      #  # ###  ####    
      ## ###### ####    
      ##############    
      ##############  ##
#  #  ############## ###
########################
,.;ADTabdeghilmnorstuvwy
```

## Merge
https://leetcode.com/problems/merge-sorted-array

Даны два отсортированных по неубыванию массива `nums1` и `nums2`. В массиве `nums1` первые `m` элементов значимы, а оставшиеся `n` ячеек - нулевые заполнители. Нужно слить `nums2` в `nums1` на месте так, чтобы результирующий массив был отсортирован по неубыванию. Слияние выполняется с конца массива, чтобы не перезаписать ещё не обработанные элементы.

Пример 1
Ввод: `nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3`
Вывод: `nums1 = [1,2,2,3,5,6]`

## Rotate
https://leetcode.com/problems/rotate-image

Дана квадратная матрица `n x n`. Нужно повернуть матрицу на 90 градусов по часовой стрелке "на месте", без использования дополнительной матрицы. Решение выполняется послойно (от внешнего слоя к центру) с помощью четверного обмена элементов.

Пример 1
Ввод: `matrix = [[1,2,3],[4,5,6],[7,8,9]]`
Вывод: `[[7,4,1],[8,5,2],[9,6,3]]`

## Query
https://coderun.yandex.ru/problem/rectangle-sum

Вам необходимо ответить на запросы - узнать сумму всех элементов числовой матрицы n x m в прямоугольнике с левым верхним углом 
(x1, y1) и правым нижним (x2, y2).
В первой строке находится числа n, m размеры матрицы (до 1000). k - количество запросов (до 100000).
Каждая из следующих n строк содержит по m чисел - элементы соответствующей строки матрицы (по модулю не превосходят 1000).
Последующие k строк содержат по 4 целых числа, разделенных пробелом x1 y1 x2 y2.
Для каждого запроса на отдельной строке выведите его результат - сумму всех чисел в элементов матрице в прямоугольнике.

Пример 1
Ввод:
```
3 3 2
1 2 3
4 5 6
7 8 9
2 2 3 3
1 1 2 3
```
Вывод:
```
28
21
```

## Check Sorted
https://leetcode.com/problems/check-if-array-is-sorted-and-rotated

Дан массив `nums`. Нужно определить, был ли он изначально отсортирован по неубыванию, а затем повёрнут циклически на некоторое количество позиций (0 и более). Возвращает `true`, если такое возможно, иначе `false`. Проверка основана на подсчёте количества "спусков" (когда следующий элемент по кругу меньше текущего) - если их не больше одного, массив можно получить поворотом отсортированного.

Пример 1
Ввод: `nums = [3,4,5,1,2]`
Вывод: true

Пример 2
Ввод: `nums = [1,2,3,4,5]`
Вывод: true

Пример 3
Ввод: `nums = [2,1,3,4,5]`
Вывод: false
