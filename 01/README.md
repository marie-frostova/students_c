# Задачи

## Ambulance

Дом состоит из подъездов, в каждом подъезде одинаковое количество этажей и одинаковое количество квартир на этаже. Известны номер квартиры, где произошёл вызов скорой помощи, номер её подъезда, этаж и количество этажей в доме. Нужно определить, в каком подъезде и на каком этаже находится квартира с заданным номером.

Формат ввода
Вводятся 5 чисел: номер искомой квартиры, номер квартиры вызова, номер подъезда вызова, этаж вызова, количество этажей в доме.

Формат вывода
Номер подъезда и этаж искомой квартиры.

Пример 1
Ввод:
```
100
50 2 4 9
```
Вывод: 3 7

## Castle If
https://coderun.yandex.ru/problem/castle-if

Даны длины трёх сторон замка `A`, `B`, `C` и размеры прямоугольного участка `D x E`. Нужно определить, можно ли расположить хотя бы две из трёх стен (в любом порядке, возможно с поворотом на 90°) так, чтобы они поместились на участке.

Формат ввода
Вводятся пять целых чисел: `A B C D E`.

Формат вывода
`YES`, если можно разместить хотя бы две стены, иначе `NO`.

Пример 1
Ввод:
```
1
1
1
1
1
```
Вывод: YES

Пример 2
Ввод:
```
2
2
2
1
1
```
Вывод: NO

## Details
https://coderun.yandex.ru/problem/details

Из `n` единиц материала можно нарезать заготовки: из каждых `k` единиц получается одна заготовка, а из каждых `m` заготовок можно собрать одну деталь. Остатки материала и заготовок можно повторно использовать для получения новых деталей. Нужно определить максимальное количество деталей, которое можно собрать.

Формат ввода
Вводятся три целых числа: `n`, `k`, `m`.

Формат вывода
Максимальное количество деталей.

Пример 1
Ввод: 10 5 2
Вывод: 4

Пример 2
Ввод: 13 5 3
Вывод: 3

Пример 3
Ввод: 14 5 3
Вывод: 4

## Equation Root
https://coderun.yandex.ru/problem/equation-root

Дано уравнение вида `a*x + b = c^2`, где `a`, `b`, `c` — целые числа. Нужно найти целочисленный корень `x` уравнения.

Формат ввода
Вводятся три целых числа: `a`, `b`, `c`.

Формат вывода
- Если решение единственно — вывести значение `x`.
- Если решений бесконечно много (`a = 0` и уравнение выполняется при любом `x`) — вывести `MANY SOLUTIONS`.
- Если решений нет — вывести `NO SOLUTION`.

Пример 1
Ввод:
```
1
0
0
```
Вывод: 0

Пример 2
Ввод:
```
1
2
3
```
Вывод: 7

Пример 3
Ввод:
```
1
2
-3
```
Вывод: NO SOLUTION

Формат ввода
Целое число `N`.

## Laptops
https://coderun.yandex.ru/problem/arrangement-laptops

Даны размеры двух прямоугольных ноутбуков (`a1 x b1` и `a2 x b2`). Нужно расположить их рядом (сложив по одной из сторон, возможно с поворотом на 90°) так, чтобы получившийся прямоугольник, вмещающий оба ноутбука, имел минимальную площадь. Нужно вывести размеры этого прямоугольника.

Формат ввода
Вводятся четыре целых числа: `a1 b1 a2 b2`.

Формат вывода
Два числа — стороны прямоугольника с минимальной площадью, вмещающего оба ноутбука.

Пример 1
Ввод: 10 2 2 10
Вывод:
```
20 2
2 20
4 10
10 4
```

Пример 2
Ввод: 5 7 3 2
Вывод:
```
9 5
5 9
```

## Min Max

Дана последовательность из `N` целых чисел (не превышающих по модулю 10 000). Нужно найти минимальное и максимальное значения последовательности, а также их порядковые номера (начиная с 1).

Формат ввода
Первая строка — количество элементов `N`. Вторая строка — сама последовательность из `N` чисел.

Формат вывода
Четыре числа: минимальное значение, его номер, максимальное значение, его номер.

Пример 1
Ввод:
5
1 7 3 4 9
Вывод: 1 1 9 5

## Parallelogram
https://contest.yandex.ru/contest/28724/problems/B

Дано `N` наборов из четырёх точек на плоскости. Для каждого набора нужно определить, образуют ли эти точки (в произвольном порядке) вершины параллелограмма.

Формат ввода
Первая строка — количество наборов `N`. Далее для каждого набора — координаты четырёх точек `x1 y1 x2 y2 x3 y3 x4 y4`.

Формат вывода
Для каждого набора точек — `YES`, если из них можно составить параллелограмм, иначе `NO`.

Пример 1
Ввод:
```
3
1 1 4 2 3 0 2 3
1 1 5 2 2 3 3 0
0 0 5 1 6 3 1 2
```
Вывод:
```
YES
NO
YES
```

## Point and Triangle
https://contest.yandex.ru/contest/28730/problems/E/

Дан прямоугольный треугольник с вершинами в точках `(0,0)`, `(d,0)`, `(0,d)`, и произвольная точка с координатами `(x,y)`. Нужно определить: если точка находится внутри треугольника или на его границе — вывести `0`. Иначе — вывести номер ближайшей к точке вершины треугольника (при равенстве расстояний выбирается вершина с меньшим номером).

Формат ввода
Число `d`, затем координаты точки `x y`.

Формат вывода
`0`, если точка внутри/на границе треугольника, иначе номер ближайшей вершины (`1`, `2` или `3`).

Пример 1
Ввод:
```
5
1 1
```
Вывод: 0

Пример 2
Ввод:
```
3
-1 -1
```
Вывод: 1

## Subway
https://contest.yandex.ru/contest/28730/problems/B

В кольцевой линии метро `n` станций, пронумерованных по кругу. Дан номер текущей станции `i` и станции назначения `j`. Нужно найти минимальное количество станций, которое нужно проехать (не считая станцию отправления и станцию назначения), двигаясь по кольцу в любом направлении.

Формат ввода
Три целых числа: `n`, `i`, `j`.

Формат вывода
Минимальное количество промежуточных станций между `i` и `j`.

Пример 1
Ввод: 100 5 6
Вывод: 0

Пример 2
Ввод: 10 1 9
Вывод: 1

## Temperature

Нужно вывести таблицу перевода температур из градусов Фаренгейта в градусы Цельсия с шагом 30 градусов Фаренгейта, начиная с 0 и заканчивая 300.

Формат вывода
Таблица с двумя столбцами: `temp_fahr` и `temp_c`.

Дополнительное задание: написать программы, выводящие таблицы квадратов и кубов, а также синусов и косинусов.

## Universal Date
https://contest.yandex.ru/contest/28730/problems/C

Даны три числа `x`, `y`, `z`, где `x` и `y` — потенциально день и месяц (или месяц и день) некоторой даты, а `z` — год. Нужно определить, можно ли однозначно определить, какое из чисел `x` или `y` является днём, а какое — месяцем (то есть являются ли оба числа `x` и `y` корректными и различными номерами месяца от 1 до 12, что делает дату неоднозначной).

Формат ввода
Три целых числа: `x y z`.

Формат вывода
`0`, если оба числа `x` и `y` могут быть месяцем (и они различны) — дата неоднозначна; иначе `1`.

Пример 1
Ввод: 1 2 2003
Вывод: 0

Пример 2
Ввод: 2 29 2008
Вывод: 1

## Watch

Часы показывают время в 24-часовом формате: `H` часов, `M` минут, `S` секунд. Нужно определить, что покажут часы через `K` секунд (от 0 до 1 000 000).

Формат ввода
Четыре целых числа: `H M S K`.

Пример
Ввод: `12 34 9 57`
Вывод: `12 35 6`

Формат вывода
Новое время в формате `H M S`.

Пример 1
Ввод: 12 34 9 57
Вывод: 12 35 6
