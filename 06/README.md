# Задачи

## Reverse Linked List
https://leetcode.com/problems/reverse-linked-list/

Дан односвязный список. Разверните его и верните новую голову списка.

Пример
```
1 -> 2 -> 3 -> 4 -> 5 -> NULL
-> 5 -> 4 -> 3 -> 2 -> 1 -> NULL
```

## Remove Nth Node From End of List
https://leetcode.com/problems/remove-nth-node-from-end-of-list/

Удалите из односвязного списка `n`-й узел с конца и верните голову измененного списка. Гарантируется, что `n` допустимо.

Пример
```
1 -> 2 -> 3 -> 4 -> 5, n = 2
-> 1 -> 2 -> 3 -> 5
```

## Middle of the Linked List
https://leetcode.com/problems/middle-of-the-linked-list/

Найдите и верните средний узел односвязного списка. Если узлов четное количество, верните второй из двух средних.

Пример
```
1 -> 2 -> 3 -> 4 -> 5
-> 3
```

## Merge Two Sorted Lists
https://leetcode.com/problems/merge-two-sorted-lists/

Даны головы двух отсортированных по возрастанию односвязных списков. Объедините их в один отсортированный список и верните его голову.

Пример
```
1 -> 3 -> 5
2 -> 4 -> 6
-> 1 -> 2 -> 3 -> 4 -> 5 -> 6
```

## Linked List Cycle
https://leetcode.com/problems/linked-list-cycle/

Определите, содержит ли односвязный список цикл. Верните `true`, если при переходе по `next` можно снова попасть в уже посещенный узел, иначе верните `false`.

Примеры
```
1 -> 2 -> 3 -> 1 -> ... -> true
1 -> 2 -> 3 -> NULL  -> false
```

## Intersection of Two Linked Lists
https://leetcode.com/problems/intersection-of-two-linked-lists/

Найдите узел, в котором пересекаются два односвязных списка, или верните `NULL`, если пересечения нет. Пересечение определяется по общему узлу, а не по совпадающим значениям.

Пример
```
A: 1 -> 2 \
           4 -> 5
B: 3 -----/
-> общий узел: 4
```

## Remove Duplicates from Sorted List
https://leetcode.com/problems/remove-duplicates-from-sorted-list/

Дан отсортированный по возрастанию односвязный список. Удалите повторяющиеся значения так, чтобы каждое значение осталось в списке только один раз.

Пример
```
1 -> 1 -> 2 -> 3 -> 3
-> 1 -> 2 -> 3
```

## LRU Cache
https://leetcode.com/problems/lru-cache/

Реализуйте кэш с ограниченной вместимостью, который вытесняет наименее недавно использованный ключ, когда при добавлении нового элемента кэш заполнен.

- `lRUCacheCreate(capacity)` создает кэш заданной положительной вместимости.
- `lRUCacheGet(key)` возвращает значение по ключу или `-1`, если ключа нет. Успешное чтение делает ключ недавно использованным.
- `lRUCachePut(key, value)` добавляет или обновляет значение. Обновление также делает ключ недавно использованным; при добавлении нового ключа в заполненный кэш вытесняется наименее недавно использованный.
- `lRUCacheFree()` освобождает кэш.

Операции получения и добавления должны в среднем выполняться за `O(1)`.

Пример
```
Создать кэш вместимостью 2
put(1, 1), put(2, 2), get(1) -> 1
put(3, 3)       // вытесняется ключ 2
get(2)          -> -1
put(4, 4)       // вытесняется ключ 1
get(1)          -> -1
get(3)          -> 3
get(4)          -> 4
```

В массиве по индексу `key` будем хранить указатель на узел списка с таким ключом. 
Сам узел списка будет содержать значение `value`.
Когда делаем `lRUCacheGet` или `lRUCachePut`, то переносим узел списка в начало списка.
Если при `lRUCachePut` количество элеменотов == `capacity`, то отрезаем у списка последний узел, так как он по построению будет самым редко используемым.
