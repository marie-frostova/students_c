# Задачи

## Anagrams
https://leetcode.com/problems/find-all-anagrams-in-a-string

Даны строки `s` и `p`, состоящие из строчных английских букв. Нужно найти все начальные индексы в строке `s`, начиная с которых находится анаграмма строки `p`. Анаграмма содержит те же буквы в том же количестве, но может быть расположена в другом порядке.

Вернуть массив индексов в любом порядке. Если подходящих фрагментов нет, вернуть пустой массив.

Пример 1
Ввод: `s = "cbaebabacd", p = "abc"`
Вывод: `[0,6]`

Пример 2
Ввод: `s = "abab", p = "ab"`
Вывод: `[0,1,2]`

Для решения используется техника скользящего окна.

## String to Integer (atoi)
https://leetcode.com/problems/string-to-integer-atoi

Реализовать функцию, преобразующую строку `s` в 32-битное знаковое целое число.

Алгоритм должен:
- пропустить начальные пробелы;
- определить знак числа по символам `-` или `+`;
- прочитать последовательность цифр;
- остановиться на первом символе, который не является цифрой;
- вернуть `0`, если цифры не были прочитаны.

Если результат выходит за диапазон от `INT_MIN` до `INT_MAX`, вернуть ближайшую границу диапазона.

Примеры
Ввод: `s = "42"`
Вывод: `42`

Ввод: `s = "   -042"`
Вывод: `-42`

Ввод: `s = "1337c0d3"`
Вывод: `1337`

Ввод: `s = "words and 987"`
Вывод: `0`

Ввод: `s = "-91283472332"`
Вывод: `-2147483648`

## String Compression
https://leetcode.com/problems/string-compression

Дан массив символов `chars`. Нужно сжать его на месте, заменяя последовательности одинаковых символов символом и количеством его повторений.

Если символ встречается один раз, количество после него не записывается. Если количество состоит из нескольких цифр, каждая цифра записывается отдельным элементом массива.

Вернуть новую длину сжатого массива. Дополнительный массив для результата использовать нельзя.

Пример 1
Ввод: `chars = ['a','a','b','b','c','c','c']`
Вывод: `6, chars = ['a','2','b','2','c','3']`

Пример 2
Ввод: `chars = ['a']`
Вывод: `1, chars = ['a']`

## Hangman

Дописать консольную игру «Виселица» на языке C.

Игра должна:
- предлагать выбрать уровень сложности;
- случайно выбирать слово из списка соответствующего уровня;
- показывать загаданное слово с символами `_` вместо неоткрытых букв;
- принимать по одной букве за ход;
- не позволять повторно использовать уже названную букву;
- открывать все вхождения угаданной буквы;
- уменьшать количество попыток при ошибке;
- отображать рисунок виселицы, слово и использованные буквы;
- завершаться победой при полном угадывании слова или поражением после исчерпания попыток;
- предлагать сыграть еще раз.

Необходимо реализовать функции (`TODO`) выбора сложности, выбора случайного слова, проверки использованных букв, отметки буквы, открытия букв, проверки окончания игры и отрисовки интерфейса.

## Palindrome
https://leetcode.com/problems/valid-palindrome

Дана строка `s`. Нужно определить, является ли она палиндромом, если учитывать только буквы и цифры и игнорировать регистр символов.

Вернуть `true`, если строка является палиндромом, и `false` в противном случае.

Пример 1
Ввод: `s = "A man, a plan, a canal: Panama"`
Вывод: `true`

Пример 2
Ввод: `s = "race a car"`
Вывод: `false`

Пример 3
Ввод: `s = " "`
Вывод: `true`

## Ransom Note
https://leetcode.com/problems/ransom-note/description/

Даны строки `ransomNote` и `magazine`, состоящие из строчных английских букв. Нужно определить, можно ли составить строку `ransomNote`, используя буквы из строки `magazine`.

Каждую букву из `magazine` можно использовать не более одного раза. Вернуть `true`, если записку можно составить, и `false` в противном случае.

Пример 1
Ввод: `ransomNote = "a", magazine = "b"`
Вывод: `false`

Пример 2
Ввод: `ransomNote = "aa", magazine = "aab"`
Вывод: `true`

Пример 3
Ввод: `ransomNote = "aa", magazine = "ab"`
Вывод: `false`

## Reverse Words in a String
https://leetcode.com/problems/reverse-words-in-a-string

Дана строка `s`, содержащая слова и пробелы. Нужно развернуть порядок слов в строке.

Словом считается последовательность непробельных символов. В результирующей строке слова должны быть разделены одним пробелом, а начальные и конечные пробелы удалены. Дополнительную строку для результата использовать нельзя.

Пример 1
Ввод: `s = "the sky is blue"`
Вывод: `"blue is sky the"`

Пример 2
Ввод: `s = "  hello world  "`
Вывод: `"world hello"`

Пример 3
Ввод: `s = "a good   example"`
Вывод: `"example good a"`

## Integer to Roman
https://leetcode.com/problems/integer-to-roman

Дано целое число `num` в диапазоне от 1 до 3999. Нужно преобразовать его в римскую запись.

Используются символы `I`, `V`, `X`, `L`, `C`, `D`, `M`, а также специальные комбинации `IV`, `IX`, `XL`, `XC`, `CD` и `CM`.

Примеры
Ввод: `num = 3`
Вывод: `"III"`

Ввод: `num = 4`
Вывод: `"IV"`

Ввод: `num = 58`
Вывод: `"LVIII"`

Ввод: `num = 1994`
Вывод: `"MCMXCIV"`

Если уникального символа нет, вернуть `-1`.
