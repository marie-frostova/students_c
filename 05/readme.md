# Задачи

## Recent Counter
https://leetcode.com/problems/number-of-recent-calls

Реализуйте счетчик недавних запросов. При каждом вызове `ping(t)` добавляется запрос с временной меткой `t`. Временные метки передаются строго по возрастанию. Нужно вернуть количество запросов за последние 3000 миллисекунд, включая текущий момент: учитываются запросы с метками в диапазоне `[t - 3000, t]`.

Реализуйте операции создания счетчика, добавления запроса и освобождения памяти.

Пример
```text
ping(1)    -> 1
ping(100)  -> 2
ping(3000) -> 3
ping(3001) -> 3
ping(3002) -> 4
```

## Valid Parentheses
https://leetcode.com/problems/valid-parentheses

Дана строка, состоящая только из символов `(`, `)`, `[`, `]`, `{` и `}`. Определите, является ли строка правильной скобочной последовательностью. Каждая открывающая скобка должна быть закрыта скобкой того же типа, а порядок вложенности должен быть корректным.

Функция `isValid` должна вернуть `true`, если строка правильная, и `false` в противном случае.

Примеры
```text
"()[]{}" -> true
"(]"     -> false
"([)]"   -> false
"{[]}"   -> true
```

## Reverse Polish Notation
https://leetcode.com/problems/evaluate-reverse-polish-notation

Дан массив токенов арифметического выражения в обратной польской записи. Токеном может быть целое число или оператор `+`, `-`, `*`, `/`. Вычислите значение выражения. Деление целых чисел округляется к нулю.

Гарантируется, что выражение корректно и после его вычисления остается ровно одно значение. Функция `evalRPN` должна вернуть это значение.

Пример
```text
["2", "1", "+", "3", "*"] -> 9
```

## Min Stack
https://leetcode.com/problems/min-stack

Реализуйте стек целых чисел, который поддерживает обычные операции стека и получение минимального элемента за `O(1)`.

Поддержите операции:
- `push(val)` — добавить элемент `val`;
- `pop()` — удалить верхний элемент;
- `top()` — вернуть верхний элемент;
- `getMin()` — вернуть минимальный элемент в стеке.

Операции `pop`, `top` и `getMin` вызываются только для непустого стека.

Пример
```text
push(3), push(5), push(2), push(1)
getMin() -> 1
pop()
top()    -> 2
getMin() -> 2
```

## My Queue
https://leetcode.com/problems/implement-queue-using-stacks

Реализуйте очередь целых чисел, используя два стека. Очередь работает по принципу FIFO: первым извлекается элемент, добавленный раньше остальных.

Поддержите операции:
- `push(x)` — добавить элемент `x` в конец очереди;
- `pop()` — удалить и вернуть первый элемент;
- `peek()` — вернуть первый элемент, не удаляя его;
- `empty()` — проверить, пуста ли очередь.

Операции `pop` и `peek` вызываются только для непустой очереди.

Пример
```text
push(1), push(2)
peek()  -> 1
pop()   -> 1
empty() -> false
```

## My Stack
https://leetcode.com/problems/implement-stack-using-queues

Реализуйте стек целых чисел, используя очереди. Стек работает по принципу LIFO: последним извлекается элемент, добавленный последним.

Поддержите операции:
- `push(x)` — добавить элемент `x`;
- `pop()` — удалить и вернуть верхний элемент;
- `top()` — вернуть верхний элемент, не удаляя его;
- `empty()` — проверить, пуст ли стек.

Операции `pop` и `top` вызываются только для непустого стека.

Пример
```text
push(1), push(2)
top()   -> 2
pop()   -> 2
empty() -> false
```
